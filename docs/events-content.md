# Konsep acara SYLUX

Judul, deskripsi ID/EN, dan rangkaian acara mengikuti informasi pengelola:

1. Gambar pertama pada kiriman terbaru: SYLUX GOT TALENT S2, ajang unjuk bakat Season 2.
2. Gambar kedua pada kiriman terbaru: LUXSTARS, sharing session dan spin wheel minigames.
3. Gambar ketiga: BOO! THE SHOW: A NIGHT OF FRIGHTS, podcast, horror storytelling, interactive minigames, dan performances.

Konsep tampil langsung di kartu dan dapat dibuka bersama rincian program pada modal. Kategori Sharing, Talent, dan Horror berasal dari jenis acara; tanggal, hadiah, atau total peserta tidak ditambahkan karena belum diberikan.

Screenshot baru terlihat dalam percakapan, tetapi tidak tersedia sebagai file di workspace saat perubahan ini disiapkan. Gambar bawaan tetap berstatus `imageKind: "illustration"` dan diberi label Ilustrasi sementara. Jangan mengubahnya menjadi dokumentasi sebelum file asli tersedia. Setelah pengelola mengirim file PNG/JPG, simpan ketiganya di `public/images`, perbarui `image` dan `alt` pada `src/data/site.ts`, lalu set `imageKind: "documentation"`. Mode dokumentasi mempertahankan warna asli dan memakai object-fit contain.

Pengelola meminta perubahan terbaru diterapkan langsung ke produksi pada 27 Oktober 2026. Ilustrasi sementara tetap diberi label sampai berkas dokumentasi asli tersedia.
